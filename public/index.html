PayPal Sandbox Testing Guide

FairFlow AI supports the PayPal Developer Sandbox when test credentials are configured. To test the live payment flow without real money, use a PayPal Sandbox Personal Test Buyer account.

Where to get your Sandbox Buyer Login:

  1. Log in to developer.paypal.com
  2. Go to Testing Tools → Sandbox Accounts
  3. Locate a Personal (Buyer) account
  4. Click the three dots (...) → View/Edit Account
  5. Copy the generated Email ID and System Password
Security Assurance: All capture events are verified server-side against the PayPal Sandbox Orders v2 API. No real currency is charged.
